`CUBE(x)`の引数`x`にカッコが付いていないことを利用し、演算子の優先順位を崩す。

`x`として`A - B`を渡すと、`x * x * x`は`A - B * A - B * A - B`すなわち`A - 2AB - B`となる。

ここで、以下のように`a, b, c`を設定する。

- `a = 1-0`
  - `CUBE(1-0) = 1 - 2 * 1 * 0 - 0 = 1`
- `b = 3-1`
  - `CUBE(3-1) = 3 - 2 * 3 * 1 - 1 = -4`
- `c = 2-1`
  - `CUBE(2-1) = 2 - 2 * 2 * 1 - 1 = -3`

こうすると、`1 + (-4) = -3`が成り立つ。
