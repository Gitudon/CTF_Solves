まず、以下のcurlコマンドで許可されているHTTPメソッドの一覧を確認する。

```bash
curl -i -X OPTIONS 'http://34.170.146.252:33368/rfc100008'
```

そうすると以下のようなレスポンスヘッダを得る。

```
HTTP/1.1 200 OK
Server: Werkzeug/3.1.8 Python/3.14.6
Date: Mon, 27 Jul 2026 01:27:32 GMT
Content-Type: text/html; charset=utf-8
Allow: F0FB4D18CF2530C2, OPTIONS
Content-Length: 0
Connection: close
```

これで許可されているメソッドが`F0FB4D18CF2530C2`だと分かったので、以下のcurlコマンドでアクセスする。

```bash
curl -X F0FB4D18CF2530C2 'http://34.170.146.252:33368/rfc100008'
```
